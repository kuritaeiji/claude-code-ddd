# ユースケース一覧

## 4.1 ユーザー管理

| ID   | ユースケース     | 説明                                       | HTTPメソッド | エンドポイント        |
| ---- | ---------------- | ------------------------------------------ | ------------ | --------------------- |
| U-01 | ユーザー登録     | メールアドレスと表示名でユーザーを作成する | POST         | /users                |
| U-02 | ユーザー非活性化 | ユーザーを非活性にする（削除はしない）。該当ユーザーはすべてのタスクの担当者から除外される。 | PATCH | /users/{id}/deactivate |

## 4.2 タスク管理（コアドメイン）

| ID   | ユースケース   | 説明                                                         | HTTPメソッド | エンドポイント   |
| ---- | -------------- | ------------------------------------------------------------ | ------------ | ---------------- |
| T-01 | タスク作成     | タイトル・説明・優先度・期日・担当者を指定して作成           | POST         | /tasks           |
| T-02 | タスク更新     | タイトル・説明・優先度・期日・ステータス・担当者一覧を更新   | PATCH        | /tasks/{id}      |
| T-03 | タスク削除     | タスクを削除する                                             | DELETE       | /tasks/{id}      |

## 4.3 クエリ（CQRS Readモデル）

| ID   | クエリ         | 説明                                                         | HTTPメソッド | エンドポイント   |
| ---- | -------------- | ------------------------------------------------------------ | ------------ | ---------------- |
| Q-01 | タスク一覧取得 | タスク一覧をフィルタ・ソート付きで担当ユーザー名とともに取得 | GET          | /tasks           |
| Q-02 | タスク詳細取得 | タスク詳細を担当ユーザー名とともに取得                       | GET          | /tasks/{id}      |
